# 延迟基准报告（timing benchmark）

> 生成命令：python realtime/bench.py --words 50 --trials 200 --seed 2026

> 合成动作数据，仅验证**管线时延**与算法可跑通性；准确率不代表真人水平。


## 1. 配置

- 词表：50 词 × 2 个模板 = 100 条模板（建库 202ms）
- 特征：归一化坐标 84 + 手部局部坐标 84 + 速度 168 = 336 维
- DTW 长度 24，粗筛 Top-8，带宽 30%
- 试次：200（总耗时 1.8s）

## 2. 识别内核（实测，ms）

| 阶段 | P50 | P95 |
|---|---:|---:|
| 归一化 + 特征构造 | 0.88 | 1.08 |
| 速度特征 | 0.15 | 0.20 |
| VAD 单步 | 0.72 | 0.95 |
| 匹配（含增量+最终） | 6.65 | 9.07 |
| 最终匹配单次 | 1.02 | 1.37 |
| 判停去抖（固定成本） | 200.00 | 200.00 |

## 3. 端点指标（实测 vs 目标）

> L1/L2 从「用户手停止移动」起算 —— 这就是 0.5s 需求的落点；L3/L4 从「句子判停完成」起算；L5 是全链路产品指标。

| 指标 | 含义 | 组成 | P95 | 目标 P95 | 结论 |
|---|---|---|---:|---:|---|
| L1 词元延迟 | 停手 → 词上屏 | 判停 200ms + 匹配 1.4ms + 渲染 17ms | 218 | 250 | PASS |
| L2 词级语音 | 停手 → 该词出声 | L1 + 音频缓存播放 25ms（假设） | 243 | 450 | PASS |
| L3 句级首字 | 判停完成 → 速成句上屏 | 模板造句 0.9µs + 渲染 17ms | 17 | 100 | PASS |
| L4 润色就绪 | 判停完成 → 润色句到达 | L3 + CoT 334ms（Mock 280ms） | 351 | 600 | PASS |
| L5 整句语音 | 停手 → 整句语音起播 | 判句 600ms + TTS 首包 180ms（假设）+ L3 | 797 | 1000 | PASS |

## 4. 智能体链路（Mock 云端，实测）

| 事件 | P50 | P95 |
|---|---:|---:|
| 快路径速成句 | 0.03 | 0.04 |
| 润色句到达 | 289.10 | 334.20 |
| 整条链路完成 | 289.12 | 334.23 |

- Mock LLM TTFB 设定 280ms（模拟云端小模型），润色结果 289ms 到达，只更新字幕、不阻塞首字；
- 工具超时/失败降级：0 次，链路均未抛出异常。

## 5. 结论

- 合成数据 Top-1 准确率 **100.0%**（仅证明管线与算法可跑通，真人数据需 W1 验收）；
- 端侧算法总开销 P95 ≈ **11.2ms/句**，远低于 0.5s 预算；
- **L1=218ms / L2=243ms，P95 满足 0.5s 目标**（0.5s 需求落在 L1/L2 这两项）；
- L5 整句语音 797ms 的瓶颈是**判句 600ms + TTS 首包**，不归入 0.5s 指标；
- 关键前提：词级音频缓存必须预热（否则 L2 要再加 TTS 首包 180–300ms，P95 会越过 450ms）。

## 6. 假设与未验证项

| 假设 | 值 | 验证方式 |
|---|---:|---|
