## 4. 为什么没有按原方案实现（3 个已批准的替换）

1. **Qwen-VL 每词调用不可能满足 0.5s**（单次 1–3s），必须移出热路径 → 端侧 DTW（见架构文档 §1/§2）。
2. **帧差法受背景/光照/衣物影响，拿不到可复用特征** → 端侧 MediaPipe 骨骼 + 运动能量 VAD。
3. **Vue3 构建链对单页演示过重，且现场没有 npm 环境风险** → 原生 ES Module + Web Worker（后续要回迁 Vue 也不影响）。

这三条都记录在 [架构决策文档 §7 改造清单](智能体体系与实时翻译架构.md) 中。
